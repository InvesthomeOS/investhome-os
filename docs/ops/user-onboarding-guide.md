# User Onboarding Guide — InvestHome OS (G11)

**Status:** Platform **not open** to all users. Wait for explicit human approval after production GO.

## Before inviting users

1. Production (or staging) environment ready and GO criteria met.
2. Demo accounts removed/disabled.
3. Roles mapped to job functions.
4. Company/brand/office settings completed.
5. Support channel published.

## Recommended invite flow

1. Admin creates user (Users admin) with least-privilege role.
2. User sets password via approved reset/invite path.
3. Enable MFA when available/enforced.
4. Walk through Home → primary workspace for their role.
5. Confirm permission denials on out-of-scope modules.

## Role starter paths

| Role | Start here |
|------|------------|
| Executive | `/dashboard/executive` |
| Sales / CRM | `/workspaces/crm` or sales routes |
| Investor relations | Investors workspace |
| Finance | Finance workspace |
| Construction / projects | Projects workspace |
| Marketing | `/workspaces/marketing` |
| Admin | `/dashboard/admin` |

## Training artifacts

Point operators to `docs/ops/support-guide.md` and in-app admin help. Do not announce public launch until approval.

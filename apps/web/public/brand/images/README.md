# Images

Brand and marketing imagery for InvestHome (hero photos, lifestyle shots, campaign stills).

## Guidance

- Prefer high-resolution masters; supply web-optimized derivatives when needed.
- Use descriptive, kebab-case filenames (for example `hero-lobby-daylight.jpg`).
- Keep rights-cleared assets only; note licensing in a sidecar or project docs if required.
- Do not store UI component screenshots here—use product/docs folders for those.

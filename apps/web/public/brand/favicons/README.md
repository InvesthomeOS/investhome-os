# Favicons

Browser and PWA favicon / touch-icon files for InvestHome.

## Guidance

- Typical set: `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, and optional `android-chrome-*.png` or a `site.webmanifest` companion if used.
- Export from the official logo masters in `../logos/`.
- Keep square artwork with adequate padding for small sizes.

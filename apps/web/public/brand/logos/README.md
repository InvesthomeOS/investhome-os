# Logos

Official InvestHome logo files. Prefer PNG with transparent background unless a format is specified elsewhere.

## Expected filenames

| File | Use |
|------|-----|
| `investhome-logo-color.png` | Full-color logo on light backgrounds |
| `investhome-logo-black.png` | Monochrome black logo |
| `investhome-logo-white.png` | Monochrome white logo on dark backgrounds |

Keep master/source exports here; do not rename casually so tooling and docs can rely on these names.

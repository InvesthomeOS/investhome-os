# Fonts

Brand typeface source files for InvestHome.

## Expected filenames

| File | Notes |
|------|--------|
| `HelveticaNeue.otf` | OpenType source / desktop use |
| `HelveticaNeue.ttc` | TrueType collection (if provided by the type kit) |

## Web-ready formats

If available, also place web-optimized files here (for example `HelveticaNeue.woff2` or family-specific `.woff2` files). Prefer WOFF2 for web delivery when licensing allows.

Do not commit fonts you are not licensed to redistribute.

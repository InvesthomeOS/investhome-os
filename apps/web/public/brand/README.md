# Brand assets

Canonical brand files for InvestHome live under this directory. Place source assets in the subfolders below; do not wire them into the app from here until a dedicated brand-integration task.

| Folder | Purpose |
|--------|---------|
| [logos/](logos/) | Primary logo variants (color, black, white) |
| [fonts/](fonts/) | Brand typefaces (desktop/source and optional web formats) |
| [guidelines/](guidelines/) | Brand, color, and typography guides |
| [images/](images/) | Brand photography and marketing imagery |
| [icons/](icons/) | Brand icon set and app icons (non-favicon) |
| [favicons/](favicons/) | Browser favicon and PWA icon files |

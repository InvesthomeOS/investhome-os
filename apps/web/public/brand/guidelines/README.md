# Guidelines

Brand documentation and visual standards for InvestHome.

## Expected contents

| Asset | Description |
|-------|-------------|
| Brand Guide PDF | Master brand book (logo usage, voice, do/don't) |
| Color Guide | Palette definitions (HEX/RGB/CMYK as applicable) |
| Typography Guide | Type hierarchy, sizes, and Helvetica Neue usage |

Name files clearly (for example `InvestHome-Brand-Guide.pdf`, `InvestHome-Color-Guide.pdf`, `InvestHome-Typography-Guide.pdf`) so they are easy to find.

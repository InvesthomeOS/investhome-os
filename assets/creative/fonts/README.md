# Creative Font Registry

Legal typefaces for Investhome OS campaign rendering.

## Currently vendored (SIL Open Font License)

| File | Family | Role intent |
|------|--------|-------------|
| `CormorantGaramond-VF.ttf` | Cormorant Garamond | DISPLAY_SERIF, EDITORIAL_SERIF, COMMERCIAL_NUMBER |
| `SourceSans3-VF.ttf` | Source Sans 3 | DISPLAY_SANS, EDITORIAL_SANS, BODY, CTA, BRAND |

OFL license texts sit beside each family. These are open fonts, not Investhome/project brand files.

## Brand / project uploads

Place licensed `.otf` / `.ttf` files here or in:

- `assets/brand/fonts/`
- `apps/web/public/brand/fonts/`

Expected Investhome kit (not redistributed in this repo):

- Helvetica Neue (Thin / Light / Regular / Medium / Bold)

The registry prefers brand-kit files when present. Do not commit fonts you are not licensed to redistribute.

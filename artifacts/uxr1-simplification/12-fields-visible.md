# 12 — Fields to Keep Visible

Daily-visible fields by surface. Everything else → Details / Advanced (`13-fields-hidden.md`).

---

## Customers (create + header)

| Field | Why |
|-------|-----|
| Full name | Identity |
| Primary phone | Contact |
| Primary email | Contact |
| Owner / assignee | Accountability |
| Lifecycle / status | Journey |
| Source | Attribution lite |
| Next follow-up | Daily action |
| Notes (short) | Context |
| Active opportunity stage (read) | Sales link |
| Preference snapshot: budget band, beds, project interest | Matching |

---

## Sales (kanban card)

| Field | Why |
|-------|-----|
| Customer name | Who |
| Stage | Pipeline |
| Project interest / unit if held | Deal object |
| Budget band or value | Prioritization |
| Owner | Accountability |
| Follow-up due | Urgency |
| Source (small) | Quality signal |

## Inventory (card)

| Field | Why |
|-------|-----|

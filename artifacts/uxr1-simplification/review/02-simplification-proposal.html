Design principles (post-approval)

Visual reset direction — wireframe-level now

Daily UX

  • Calm real-estate OS: clear hierarchy, generous whitespace
  • One composition per viewport; brand-forward shell
  • Cards only where interaction needs them (inventory/project grids, kanban)
  • Inventory & Projects: card grid primary; table = power toggle
  • Progressive disclosure on create/edit forms
  • Wizards: short happy path (e.g. campaign 12→5 steps)

Charts & motion

  • Every widget: definition · time · source · drill · empty
  • Exceptions: Sales FunnelChart · Unit Availability DonutChart
  • Prefer Bar / Area / Sparkline / Progress elsewhere
  • Motion: board transitions, card hover, empty→ready — not noise
  • Avoid purple-gradient / cream-serif / broadsheet clichés
  • No Inter/Roboto stacks — keep distinctive DS fonts

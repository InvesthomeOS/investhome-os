# Golden Baseline Analysis — Creative Quality Lock finals

Source: `artifacts/creative-quality-lock/` PRICE / LOCATION / LIFESTYLE finals.
Purpose: DESIGN PRINCIPLES (not pixel copy). Current simplified editable stack = FAIL reference.

## Shared principles
1. **Composition** — Full-bleed photograph; type lives in planned contrast zones, not a top-to-bottom stack.
2. **Hierarchy** — One primary read in ~2s; support quieter; single CTA; logo once.
3. **Typography** — Serif/display for hero; sans for support/price/CTA; clear size jumps.
4. **Image treatment** — Master asset preserved; contrast via overlays/gradients, not AI regrade loops.
5. **Negative space** — Premium breathing room; density sparse unless price intent needs medium.
6. **Overlays / gradients** — Localized dark (offer stack) or light (editorial top) text-safe zones.
7. **Logo** — Real project mark; top-left (price) or top-center (place/lifestyle/brand).
8. **CTA** — Proportionate gold/action pill; never tiny footer text.
9. **Spacing / margins** — ~6–8% side margins; intentional rhythm eyebrow → headline → support → CTA.
10. **Alignment** — Intent-specific (left offer stack / center editorial / place-led split).
11. **Focal point** — Reserve image subject; do not cover with equal-weight copy blocks.
12. **Premium feel** — Structure + restraint, not more widgets.

## PRICE
- Lower-third dark gradient; offer stack (eyebrow pill, headline, price frame, badge, CTA).
- Strong price hierarchy ($list struck / $offer large / badge).
- Controlled urgency; medium density.

## LOCATION
- Place-led headline (often centered); top dark for logo/eyebrow contrast.
- Minimal supporting facts mid-left; divider; CTA bottom-left.
- Architecture/street asset as focal; sparse density.

## LIFESTYLE
- Image-dominant editorial; top light cream zone for dark type; soft bottom dark for captions/CTA.
- Centered logo + eyebrow + large headline; feature row near bottom; soft gold CTA.
- Sparse density; premium spacing.
